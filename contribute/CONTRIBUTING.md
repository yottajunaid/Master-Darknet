# Contributing to Master-Darknet

Thank you for your interest in contributing to **Master-Darknet**.

This project is a **research-driven, educational exploration** of the Deep Web, Dark Web, and anonymity networks. Contributions are welcome — but only when they align with the project’s **academic, ethical, and technical standards**.

* * *

## 🧱 Content Standards

All contributions must meet these standards:

### Accuracy

- Claims should be verifiable
    
- Prefer primary sources, academic papers, or official documentation
    
- Avoid vague or sensational language
    

### Clarity

- Write in clear, structured Markdown
    
- Explain technical terms on first use
    
- Avoid unnecessary jargon
    

### Neutral Tone

- No glorification of crime or “darkness”
    
- No dramatic or clickbait language
    
- Objective, explanatory writing is preferred
    

* * *

## 🗂️ Repository Structure

Documentation follows this hierarchy:

`PART └── MODULE └── Sections (Markdown/MDX pages)`

- Do **not** break existing structure
    
- New modules or parts should be discussed first via an Issue
    
- Automation scripts should be reproducible and documented
